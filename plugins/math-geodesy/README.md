# math-geodesy

Abstract math skills for geodetic coordinates, reference ellipsoids, and datum transformations.

## Skills

| Skill | Description |
|-------|-------------|
| [geodetic-coordinate-bounds](.apm/skills/geodetic-coordinate-bounds) | Abstract math for geodetic coordinate constraints: valid ranges, wrap semantics, and coordinate type distinctions |
| [helmert-datum-transformation](.apm/skills/helmert-datum-transformation) | Abstract math for the 7-parameter (Helmert) similarity transformation used to convert coordinates between geodetic datums |
| [reference-ellipsoids](.apm/skills/reference-ellipsoids) | Abstract math for reference ellipsoids used in geodesy |
